# TOSCA

Study folder for Tricentis Tosca. It assumes you already design tests and have automated them in code. The lessons skip testing theory and teach the Tosca object model.

Tosca Commander is a Windows application and needs a license. The paper labs in `lab/` can be done here. The Academy exercises need Commander.

## Study order

1. [Lesson 1. The model](lessons/01-the-model.md)
2. [Lab 1. Worked login](lab/01-worked-login.md)
3. [Lesson 2. Modules and XScan](lessons/02-modules-and-xscan.md)
4. [Lesson 3. TestCases and ActionModes](lessons/03-testcases-and-actionmodes.md)
5. [Lesson 4. Buffers, parameters, and libraries](lessons/04-buffers-parameters-libraries.md)
6. [Lesson 5. Test design, API, and execution](lessons/05-test-design-api-execution.md)

9. [Progress](lab/progress.md)

## First sitting

Read lesson 1, then copy the shape of lab 1 from memory onto paper or into a new note under `lab/`. If you can place every value in the right column (control, ActionMode, value) without looking, the model has stuck.

Official course, after a license is available: [Tricentis Tosca Fundamentals — Automating web application testing](https://academy.tricentis.com/tricentis-tosca-fundamentals-automating-web-application-testing) (formerly Automation Specialist Level 1). Do Academy exercises 01 through 11 before opening TestCaseDesign or API Scan.

## What this folder does not contain

No Tosca workspace, no license, and no application passwords. Do not paste credentials, card numbers, or a live checkout session into these notes.
